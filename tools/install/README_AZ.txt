BAKI — GTA San Andreas (PC, orijinal 1.0) üçün xəritə
=====================================================

Bu mod San Andreas-ın bütün xəritəsini Bakının bu ərazisi ilə əvəz edir:
Biləcəri, Dərnəgül, 9-cu mikrorayon, Nəsimi, Yasamal, Yeni Yasamal, 28 May,
Heydər Əliyev Mərkəzi, Ağ Şəhər və Dənizkənarı Bulvar (Xəzər sahili, Böyükşor
və Qanlı göl daxil).

Nələr var:
  * Real yol şəbəkəsi (OpenStreetMap): prospektlər, küçələr, həyət yolları,
    ayırıcı zolaqlar, dairəvi yollar, estakadalar (sütunlu körpülər),
    tunel/alt keçid girişləri, səkilər və bordürlər.
  * Real relyef (Bakı amfiteatrı, Yasamal yamacı) və su: Xəzər dənizi,
    Böyükşor gölü, Qanlı göl, Yasamal gölü.
  * Binalar: GTA San Andreas-ın ORİJİNAL bina modelləri, Bakının real bina
    konturlarına görə seçilib yerləşdirilib (34 000+ bina).
  * Görməli yerlər: Heydər Əliyev Mərkəzi, Alov qüllələri (gecə alov kimi
    işıqlanır), Heydər məscidi, Qız qalası.
  * Mağaza/market adları real adlarla (Bravo, Araz, Bazarstore, apteklər,
    banklar, kafelər ...), mavi küçə adı lövhələri, zebra keçidləri.
  * Azərbaycan yol nişanları (STOP, yol ver, piyada keçidi, giriş qadağandır,
    sürət həddi, avtobus dayanacağı, metro "M" ...) - maşın vuranda yıxılır.
  * Küçə işıqları, 30 000+ ağac, avtobus dayanacaqları, skamyalar, həyətlərdə
    və dayanacaqlarda park olunmuş maşınlar.
  * Maşın və piyada trafiki (AI yolları), real yerlərində svetoforlu qovşaqlar
    (svetoforun rəngi ilə maşınların davranışı eynidir).
  * Radar və menyu xəritəsi — Bakı xəritəsi.
  * Ekranda rayon adları: Nəsimi, Yasamal, Biləcəri, 9-cu mikrorayon və s.
  * Sərbəst gəzinti (free roam): oyun Heydər Əliyev Mərkəzinin yanında başlayır,
    xəstəxanalar və polis bölmələri real yerlərindədir.

QURAŞDIRMA
  1. GTA San Andreas PC 1.0 (təmiz, modsuz versiya tövsiyə olunur).
     Diskdə ~500 MB boş yer lazımdır.
  2. Bu qovluqdakı INSTALL.bat faylını açın (oyun "Program Files"-dadırsa,
     sağ klik -> "Run as administrator").
  3. Açılan pəncərədə GTA San Andreas qovluğunu seçin (gta_sa.exe olan qovluq).
  4. Oyunu açın və "Start New Game" seçin. Köhnə save-ləri YÜKLƏMƏYİN.

Quraşdırıcı dəyişdirdiyi hər şeyin (gta3.img qovluğu, data\object.dat,
gxt faylları ...) ehtiyat surətini <oyun>\baku_backup qovluğuna yazır. Geri qaytarmaq üçün UNINSTALL.bat — oyun orijinal vəziyyətinə
(bayt-bayt) qayıdır.

Python istifadəçiləri üçün alternativ:
  python installer\baku_install.py install   "C:\...\GTA San Andreas"
  python installer\baku_install.py uninstall "C:\...\GTA San Andreas"

QEYDLƏR
  * Xəritə 0.675 miqyasındadır (8.9 x 8.7 km-lik ərazi San Andreas-ın 6 x 6 km
    dünyasına sığsın deyə). Yollar SA maşınları üçün 5.4 m-lik zolaqlarla qurulub.
  * Hekayə missiyaları yoxdur — bu, total conversion (sərbəst gəzinti) modudur.
  * modloader istifadə edirsinizsə, digər xəritə modlarını söndürün.
  * SA şrifti ə, ş, ğ, ı hərflərini dəstəkləmir — ekranda ä, sh, gh, i kimi görünür.
